Guía de Uso y Publicación

FIUBA Path Explorer — Path 1: Somos Libres

Interacción Básica

  • Clic en cualquier materia: Alterna entre aprobada y pendiente con actualización instantánea en cascada.
  • Pasa el mouse sobre una materia: Resalta visualmente en azul las correlativas requeridas y las materias dependientes que desbloquea.
  • Filtro por Carrera: Selecciona "Ambas Carreras", "Solo Sistemas" o "Solo Informática" en la barra superior para ajustar la visión del plan de estudio.

Publicar en GitHub Pages

  1. Crea un repositorio público en GitHub (ejemplo: fiuba-plan-carrera).
  2. Sube este archivo renombrándolo como index.html a la rama principal (main/master).
  3. En GitHub, ve a Settings > Pages.
  4. En "Build and deployment / Branch", selecciona main y carpeta / (root). Haz clic en Save.
  5. ¡Listo! En pocos segundos tendrás tu URL pública para compartir tu avance.
